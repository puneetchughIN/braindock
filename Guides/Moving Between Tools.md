# Moving Between Tools

## Files first

Obsidian is the reading and editing interface; Markdown is the durable record. Standard relative links keep the starter navigable in other editors and on GitHub. Obsidian-only features such as the graph are conveniences, not required memory.

## Move a vault

Close editors, copy the complete working folder using your chosen private backup or transfer method, and open the new location. Preserve attachments and relative paths. Verify the restored copy before retiring the original.

Avoid recording home-directory paths as canonical locations. Keep credentials and machine-specific agent registrations outside the shared vault.

## Change an AI tool

Grant access deliberately. Point the new tool to AGENTS.md and the selected project entry. No vendor-specific memory export is required for the records kept here. Tool permissions, authentication, and integrations still need their own setup.

## Git is optional

Version control can preserve change history, but it is not required to use BrainDock. If used, keep the populated vault private. A template update should be reviewed and selectively adopted, not blindly overwrite personal notes. Git history can retain deleted sensitive content.

See [Checking and Recovery](Checking%20and%20Recovery.md) for a restoration check.
