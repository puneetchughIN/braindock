# BrainDock starter plan

## Outcome

A private, reviewable Obsidian starter demonstrating portable knowledge and an agent memory layer. Empty project and knowledge indexes; generic instructions and blank templates only.

## Agreed boundaries

Build from an empty directory and fresh Git history. No import or synchronization from personal vaults. No public visibility change. Defer license selection until owner review. Optional AI and Python tooling; no community-plugin requirement.

## Production sequence

1. Author navigation, conventions, privacy guidance, and templates.
2. Add guides and portable resume, close-session, and portfolio prompts.
3. Build a read-only structural checker using focused regression tests for broken navigation, duplicate names, placeholders, and path boundaries.
4. Exercise creation, relocation, and fresh-reader comprehension with fictional material in a disposable copy. Open the clean starter in Obsidian.
5. Review the complete candidate and history, commit the scoped files, create and push only to a private repository, and verify remote visibility.

## Acceptance

The starter opens without community plugins; links resolve; new projects have one state owner; fresh-reader summaries can locate state, decisions, and next steps; relocation preserves navigation; checker tests pass; the shipped tree contains no populated personal records. Verification records distinguish observed behavior from limitations.

## Deferred

Public release, final license, automatic retrieval, synchronization, background agents, advanced repository embedding, and private-vault migration.
