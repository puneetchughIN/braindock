# Close a Work Session

Use this when the user explicitly asks to preserve the outcome of the current session for a named project. Resolve the exact project first.

Review the actual changes and evidence. Update the named current-state record only if state changed. Record durable choices with reasoning in the decision log. Update unresolved work and next actions in open threads. Append a short session entry for meaningful changes. Promote a cross-project conclusion to Knowledge only when supported, linking to its origin.

Preserve other writers' edits. Do not invent completed work, change lifecycle silently, or save a transcript or chat-summary archive. Keep scratch outside the vault. If there is no meaningful change, say so without manufacturing an entry.

Report the records changed, the next move, and any uncertainty. This invocation authorizes bounded memory updates; it does not authorize commits, pushes, external disclosure, or publication.
